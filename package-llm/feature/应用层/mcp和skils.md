2.2.2 MCP与Skill区别

Claude Skills 是 Anthropic 公司于2025年10月推出的一项功能，这是一种让Claude获取新功能的模块化能力包，允许用户为 Claude 添加自定义的能力和工具。其核心是一个包含 SKILL.md文件、脚本与资源文件的文件夹。当Claude识别到当前任务与某个已安装技能的描述相匹配时，它会自动加载并调用该技能，从而像调用“工具箱里的工具”一样完成任务，无需每次都从头生成代码或指令。官方也给出了MCP与Skill的区别介绍：
