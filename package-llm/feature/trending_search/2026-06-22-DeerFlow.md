### 项目简介

DeerFlow 是字节跳动（ByteDance）开源的 **SuperAgent Harness**（超级 Agent 编排框架）。它不是一个简单的聊天机器人，而是一个完整的 Agent 运行时，能够编排子 Agent、管理记忆、控制沙箱环境、调用工具与技能，完成从几分钟到数小时的复杂任务。

**核心定位**：一个"能研究、能编码、能创作"的全能 Agent 框架。它通过沙箱、记忆、工具、技能、子 Agent 和消息网关六大核心模块，处理不同层级的任务。

> DeerFlow 2.0 是全新重写版本，与 v1 无代码共享。v1 分支仍在维护。

### 核心功能详解

#### 1. 技能系统（Skills & Tools）—— 让 Agent 能做"几乎任何事"

技能是 DeerFlow 最核心的设计。每个技能是一个 Markdown 文件（`SKILL.md`），定义了工作流、最佳实践和参考资料。

**内置技能包括**：

- 🔍 深度研究（research）
- 📊 报告生成（report-generation）
- 📽️ 幻灯片制作（slide-creation）
- 🌐 网页生成（web-page）
- 🎨 图像生成（image-generation）
- 🎬 视频生成

**关键设计**：

- **按需加载**：技能只在任务需要时加载，保持上下文窗口精简，即使对 token 敏感的模型也能高效运行
- **显式激活**：用户可通过 `/skill-name` 命令激活特定技能，如 `/data-analysis analyze uploads/foo.csv`
- **可扩展**：完全支持自定义技能、替换内置技能、组合成复合工作流
- **MCP 支持**：支持通过 MCP 服务器扩展工具能力，支持 OAuth token 流

**与 Claude Code 集成**：
DeerFlow 提供 `claude-to-deerflow` 技能，可以直接从 Claude Code 与 DeerFlow 实例交互——发送研究任务、检查状态、管理线程，无需离开终端。

```Shell
// 代码块
# 安装 claude-to-deerflow 技能
npx skills add https://github.com/bytedance/deer-flow --skill claude-to-deerflow
```

#### 2. 子 Agent 编排（Sub-Agents）—— 复杂任务自动分解

DeerFlow 的 lead agent 可以动态创建子 Agent：

- 每个子 Agent 拥有**独立的作用域上下文、工具和终止条件**
- 子 Agent 可**并行运行**，提高效率
- 完成后向 lead agent 汇报结构化结果
- lead agent 综合所有结果生成最终输出

**典型场景**：一个深度研究任务可以分发为十几个子 Agent，各自探索不同角度，最终汇聚为一份完整报告、网站或带生成视觉效果的幻灯片。

#### 3. 沙箱与文件系统（Sandbox & File System）—— Agent 拥有"自己的电脑"

DeerFlow 为每个任务提供独立的执行环境：

- **文件系统视图**：skills、workspace、uploads、outputs
- **文件读写**：Agent 可以读取、写入、编辑文件
- **图像查看**：支持查看图片
- **Shell 执行**：支持执行 shell 命令

**三种执行模式**：

| 模式 | 说明 |
| --- | --- |
| Local Execution | 直接在宿主机运行沙箱代码 |
| Docker Execution | 在隔离的 Docker 容器中运行 |
| Docker + Kubernetes | 通过 provisioner 服务在 Kubernetes Pod 中运行 |

```
// 代码块
# 沙箱容器内路径结构
/mnt/user-data/
├── uploads/          ← 用户上传的文件
├── workspace/        ← Agent 工作目录
└── outputs/          ← 最终交付物
```

#### 4. 上下文工程（Context Engineering）

- **隔离子 Agent 上下文**：每个子 Agent 运行在独立上下文中，互不干扰
- **主动摘要**：会话中主动总结已完成的子任务，将中间结果卸载到文件系统，压缩不再立即相关的内容
- **严格工具调用恢复**：当 provider 或中间件中断工具调用循环时，自动注入占位工具结果，防止 OpenAI 兼容推理模型报错

#### 5. 长期记忆（Long-Term Memory）

- 跨会话持久化记忆：用户画像、偏好、积累的知识
- 越用越懂你：了解你的写作风格、技术栈、常用工作流
- 本地存储，用户完全控制
- 自动跳过重复事实条目，避免无限累积

#### 6. 消息渠道（IM Channels）—— 多平台接入

DeerFlow 支持从多个即时通讯平台接收任务，无需公网 IP：

| 渠道 | 传输方式 | 难度 |
| --- | --- | --- |
| Telegram | Bot API (长轮询) | 简单 |
| Slack | Socket Mode | 中等 |
| 飞书/钉钉 | WebSocket | 中等 |
| 微信/企微 | 长轮询/WebSocket | 中等 |

#### 7. 嵌入式 Python 客户端

DeerFlow 可作为 Python 库嵌入使用，无需启动完整 HTTP 服务：

```Python
// 代码块
from deerflow.client import DeerFlowClient

client = DeerFlowClient()
response = client.chat("帮我分析这篇论文", thread_id="my-thread")

# 流式响应
for event in client.stream("hello"):
    if event.type == "messages-tuple" and event.data.get("type") == "ai":
        print(event.data["content"])

# 管理能力
models = client.list_models()
skills = client.list_skills()
```

### 使用方式

#### 快速开始

```Shell
// 代码块
# 1. 克隆仓库
git clone https://github.com/bytedance/deer-flow.git
cd deer-flow

# 2. 运行交互式配置向导（约2分钟）
make setup

# 3. 验证配置
make doctor

# 4. 启动服务
make dev
```

#### Docker 部署（推荐）

```Shell
// 代码块
# 开发模式（热重载）
make docker-init    # 仅首次或镜像更新时执行
make docker-start

# 生产模式
make up    # 构建镜像并启动所有服务
# 访问: http://localhost:2026
```

### 落地实践场景

#### 1. 深度研究

DeerFlow 的"深度研究"能力是其最突出的应用场景。用户可以提交一个复杂问题（如"分析2025年AI Agent市场趋势"），DeerFlow 会自动：

- 分解为多个研究子任务
- 并行搜索和分析不同维度
- 综合生成结构化研究报告

#### 2. 自动化报告/幻灯片生成

从原始数据或研究材料自动生成报告和幻灯片，支持图像和视频生成，适合：

- 技术调研报告
- 竞品分析
- 项目演示材料

#### 3. 代码辅助开发

结合 Claude Code 集成，可作为高级编码 Agent 使用：

- 复杂代码重构
- 自动化测试生成
- 跨文件分析和修改

#### 4. 多平台智能助手

通过 IM 渠道接入，实现：

- 企业微信/飞书/钉钉智能客服
- Telegram/Slack 自动化助手
- 24小时不间断服务

#### 5. 嵌入式应用场景

作为 Python 库嵌入到其他系统中：

- SaaS 产品的 AI 能力增强
- 内部工具自动化
- 数据分析平台集成

### 技术架构分析

#### 架构栈

| 层级 | 技术 |
| --- | --- |
| **LLM 交互** | LangChain |
| **多 Agent 编排** | LangGraph |
| **后端** | Python (uv + FastAPI/Gateway) |
| **前端** | Node.js 22+ |
| **沙箱** | Docker / Kubernetes |
| **消息网关** | 内置 Gateway API |

#### 与 LangGraph 兼容

DeerFlow 的 Gateway 拥有 `/api/langgraph/*` 路由，完全兼容 LangGraph 的 API 格式，可以与 LangGraph 生态无缝集成。

### 个人评价与建议

#### 优势

1. **⭐ 字节跳动背书**：72K+ stars，企业级开源项目，社区活跃度高
2. **⭐ 全能 Agent 框架**：研究、编码、创作三位一体，不是单一功能 Agent
3. **⭐ 强大的技能系统**：按需加载、可扩展、支持 MCP，设计优秀
4. **⭐ 子 Agent 编排**：并行执行、独立上下文，适合复杂任务分解
5. **⭐ 多平台 IM 接入**：无需公网 IP，支持国内主流平台（微信、企微、飞书、钉钉）
6. **⭐ 长期记忆**：跨会话记忆，越用越智能
7. **⭐ 嵌入式使用**：可作为 Python 库嵌入，灵活度高

#### 不足

1. **资源消耗较大**：推荐配置 8 vCPU / 16 GB RAM，对轻量级用户不够友好
2. **部署复杂度高**：相比简单 Agent 框架，Docker + 多服务编排门槛较高
3. **安全风险**：默认支持 shell 执行，需要严格的安全配置
4. **2.0 新框架**：作为重写版本，生态和稳定性还需时间验证

#### 使用建议

- **适合团队**：研发团队、技术调研团队、AI 产品团队
- **不适合**：轻量级个人使用、资源受限环境
- **推荐场景**：深度研究、自动化报告生成、企业级 AI Agent 平台
