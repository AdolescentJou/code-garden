# 稠密向量与稀疏向量简介

## 一、核心区别一句话总结

- **稠密向量**：靠语义理解，抓意思、抓上下文、抓深层关联。
- **稀疏向量**：靠关键词 / 词频匹配，抓字面、抓精确词、抓术语。

## 二、详细对比

### 1. 稠密向量（Dense Vector）

一般由 BERT、Contriever、E5、BGE 这类模型生成。

**特点：**

- 维度通常：768 / 1024 维
- 每个维度都有非零值
- 表示语义、上下文、含义
- 泛化能力强：同义词、相关词、转述都能匹配

**优点：**

- 理解语义相似
- 适合自然问答、长文本、意图理解
- 抗改写能力强

**缺点：**

- 对精确关键词、专业术语不敏感
- 容易把 "长得不像但意思像" 的乱匹配

**典型场景：**

- 智能问答
- 长文档检索
- 意图理解
- 语义相似搜索

### 2. 稀疏向量（Sparse Vector）

典型代表：BM25、TF-IDF、SPLADE、uniCOIL 等。

**特点：**

- 维度一般是词典大小（几万～几十万维）
- 大部分值为 0，只有少数维度非零
- 本质是：词权重 = 出现频率 + 重要性

**优点：**

- 关键词命中极强
- 专业术语、实体、精确词匹配无敌
- 可解释、速度快
- 不需要训练

**缺点：**

- 不理解语义
- 同义词、转述、换说法就不行

**典型场景：**

- 法律 / 医疗 / 专利等强术语文档
- 精确关键词检索
- 实体搜索（人名、地名、型号、编号）
- 短文本、标题检索

## 三、最简单区分口诀

> 想搜 **"意思"** → 稠密向量
>
> 想搜 **"词"** → 稀疏向量

## 四、现代 RAG 最佳实践：混合检索（最稳）

现在工业界基本都用：**稠密向量 + 稀疏向量 = 混合检索（Hybrid Search）**

- **稠密向量**：负责语义召回
- **稀疏向量**：负责关键词 / 术语召回
- 再用 **Rerank 模型**重排
