# RAG 文本智能切片（Chunking）：基于语义边界的分段方法

## 核心需求确认

文本转向量前的切片环节，如何避免在关键词 / 关键语义处断开，通过**基于语义边界的智能切片方法**，保证每个片段的语义完整性，提升后续检索召回效果。

---

## 一、好的切片的核心原则

1. **语义完整性**：每个切片是一个 "完整的语义单元"（比如完整的句子、段落、技术概念）
2. **长度可控**：切片长度适配 Embedding 模型的输入上限（比如大部分模型支持 512/1024 Token）
3. **适度重叠**：相邻切片保留少量重叠内容，避免跨切片的语义丢失（比如前一个切片末尾和后一个切片开头重叠 10%）

> 简单说：**先按语义分大块，再在大块内按长度微调，绝不硬切语义。**

---

## 二、3 种实用的智能切片方法（从易到难）

### 方法 1：基础版 —— 按自然分隔符切片（优先）

这是最易实现、效果也不错的方案，核心是**优先按 "自然语义边界" 拆分**，比如段落 → 句子 → 分号，最后才按长度兜底。

**核心步骤：**

1. 先按段落分隔符（`\n\n`）拆分文档，得到段落级大块
2. 对每个段落，按句子分隔符（`。！？；`）拆分成句子
3. 把句子逐个合并，直到接近模型 Token 上限（比如 400 Token），形成一个切片
4. 若单个句子超长（比如超过模型上限），再按 Token 长度硬切（兜底）
5. 相邻切片保留重叠窗口（比如最后 1~2 个句子），避免语义断裂

**代码示例（中文文本智能切片）：**

```python
import re
from transformers import AutoTokenizer

# 加载Tokenizer（匹配Embedding模型的Token规则，这里用BGE-M3）
tokenizer = AutoTokenizer.from_pretrained("BAAI/bge-m3")

def smart_chunking(
    text: str,
    max_tokens: int = 400,  # 切片最大Token数（小于模型上限512）
    overlap_tokens: int = 50,  # 重叠Token数
    separators: list = ["\n\n", "\n", "。", "！", "？", "；", "，"]  # 语义分隔符优先级
) -> list:
    """
    基于语义边界的智能切片
    """
    # 步骤1：按分隔符递归拆分文本为小单元（句子/短句）
    def split_by_separator(text, separators):
        if not separators:
            return [text]
        sep = separators[0]
        parts = re.split(f"({sep})", text)  # 保留分隔符
        parts = [p + sep for i, p in enumerate(parts) if i % 2 == 0 and p]  # 拼接内容+分隔符
        if len(parts) == 1:
            return split_by_separator(text, separators[1:])  # 下一个分隔符
        return parts

    # 拆分出最小语义单元（句子/短句）
    semantic_units = split_by_separator(text, separators)
    # 过滤空单元
    semantic_units = [unit.strip() for unit in semantic_units if unit.strip()]

    # 步骤2：合并语义单元为切片（控制Token长度）
    chunks = []
    current_chunk = []
    current_tokens = 0

    for unit in semantic_units:
        # 计算当前单元的Token数
        unit_tokens = len(tokenizer.encode(unit))

        # 如果加入当前单元会超上限，且当前chunk非空，则保存当前chunk
        if current_tokens + unit_tokens > max_tokens and current_chunk:
            # 拼接当前chunk
            chunk_text = "".join(current_chunk).strip()
            chunks.append(chunk_text)

            # 处理重叠：保留最后N个Token对应的内容作为下一个chunk的开头
            overlap_text = "".join(current_chunk)
            overlap_encoded = tokenizer.encode(overlap_text)[-overlap_tokens:] if overlap_tokens > 0 else []
            overlap_text = tokenizer.decode(overlap_encoded).strip()

            # 重置当前chunk为重叠内容 + 当前单元
            current_chunk = [overlap_text, unit] if overlap_text else [unit]
            current_tokens = len(tokenizer.encode("".join(current_chunk)))
        else:
            # 加入当前单元
            current_chunk.append(unit)
            current_tokens += unit_tokens

    # 加入最后一个chunk
    if current_chunk:
        chunk_text = "".join(current_chunk).strip()
        chunks.append(chunk_text)

    return chunks

# ---------------------- 测试示例 ----------------------
# 模拟笔记系统中的长文本（包含完整技术概念）
long_text = """
Python实现RAG混合检索的核心是归一化和权重融合。
归一化的目的是统一稠密向量和稀疏向量的分数量纲，避免某类向量的分数占主导。
具体步骤为：1）分别计算稠密向量的余弦相似度和稀疏向量的加权内积；2）对两类分数做Min-Max归一化；3）按权重融合（如稠密0.6，稀疏0.4）。
如果跳过归一化步骤，稀疏向量的高分值会覆盖稠密向量的语义匹配结果，导致检索结果只匹配关键词，丢失语义信息。
"""

# 智能切片
chunks = smart_chunking(long_text, max_tokens=200, overlap_tokens=30)

# 输出结果
print("切片结果：")
for i, chunk in enumerate(chunks):
    token_num = len(tokenizer.encode(chunk))
    print(f"\n【切片{i+1}】（Token数：{token_num}）")
    print(chunk)
```

### 方法 2：进阶版 —— 基于文档结构的切片（适合结构化文档）

如果笔记系统主要处理 Markdown、PDF、Word 等结构化文档，可结合文档结构切片：

- **Markdown**：按标题（`#` / `##`）拆分，每个标题下的内容作为一个大切片，再按句子微调
- **PDF/Word**：按页码、章节、标题拆分，优先保证章节 / 标题下的语义完整
- **代码文档**：按函数、类、代码块拆分（比如 Python 的 `def` / `class`）

**示例（Markdown 结构切片）：**

```python
def markdown_chunking(markdown_text: str) -> list:
    """Markdown按标题切片"""
    # 按标题拆分（匹配##/###等）
    sections = re.split(r"(^#{1,6} .+?$)", markdown_text, flags=re.MULTILINE)
    chunks = []
    current_section = ""
    for part in sections:
        if part.startswith("#"):  # 标题行
            if current_section:
                chunks.append(current_section.strip())
            current_section = part  # 新标题
        else:
            current_section += part
    if current_section:
        chunks.append(current_section.strip())
    # 对每个标题下的内容再按句子微调（调用方法1）
    final_chunks = []
    for chunk in chunks:
        final_chunks.extend(smart_chunking(chunk, max_tokens=400))
    return final_chunks
```

### 方法 3：高级版 —— 基于模型的语义切片（适合复杂文本）

如果文本无明显分隔符（比如纯口语化文本、无标点的长文本），可借助语义分割模型（如 SemanticChunker、LangChain 的 `RecursiveCharacterTextSplitter` + 语义检测）：

1. 用 Embedding 模型计算每个句子的向量
2. 计算相邻句子向量的余弦相似度
3. 相似度低于阈值（比如 0.7）时，判定为语义边界，在此处切片
4. 保证每个切片内的句子语义高度相关

**核心思路代码（简化版）：**

```python
from sentence_transformers import SentenceTransformer

def semantic_boundary_chunking(text: str, threshold: float = 0.7):
    # 拆分成句子
    sentences = re.split(r"[。！？]", text)
    sentences = [s.strip() for s in sentences if s.strip()]
    # 生成句子向量
    model = SentenceTransformer("BAAI/bge-small-zh-v1.5")
    sentence_embeddings = model.encode(sentences)
    # 找语义边界
    boundaries = [0]
    for i in range(1, len(sentences)):
        sim = np.dot(sentence_embeddings[i-1], sentence_embeddings[i])
        if sim < threshold:
            boundaries.append(i)
    boundaries.append(len(sentences))
    # 合并边界内的句子
    chunks = []
    for i in range(len(boundaries)-1):
        start = boundaries[i]
        end = boundaries[i+1]
        chunk = "。".join(sentences[start:end]) + "。"
        chunks.append(chunk)
    return chunks
```

## 三、工业界落地的最佳实践

1. **优先用方法 1（自然分隔符）**：80% 的场景能满足需求，实现简单、效率高
2. **结构化文档加方法 2**：Markdown / PDF 优先按标题 / 章节拆分，再按句子微调
3. **复杂文本才用方法 3**：模型语义切片耗时稍高，适合无规则的长文本
4. **统一 Token 计算**：切片的长度限制一定要用「Token 数」而非「字符数」（中文 1 个汉字 ≈ 1 Token，英文 1 个单词 ≈ 1 Token，标点 / 空格也占 Token）
5. **重叠窗口必加**：重叠比例建议 10%~20%，避免跨切片的语义丢失（比如 "RAG 混合检索" 跨两个切片时，重叠能保证检索到）

---

## 总结

- **核心思路**：切片优先按「自然语义边界」（段落、句子、标点）拆分，而非固定长度硬切，只有在语义单元超长时才兜底按长度拆分
- **关键技巧**：
  - 用 **Token 数**而非字符数控制长度（匹配 Embedding 模型输入上限）
  - 相邻切片保留**重叠窗口**，避免跨切片语义断裂
  - 结构化文档结合**文档结构**（标题 / 章节）切片
- **落地优先级**：自然分隔符切片 → 结构切片 → 模型语义切片（从易到难，按需选择）

> 这样切片后的每个向量片段都能保留完整语义，不会出现 "关键词被切断" 的问题，后续检索时能精准召回包含完整语义的片段，大幅提升 RAG 的效果。
