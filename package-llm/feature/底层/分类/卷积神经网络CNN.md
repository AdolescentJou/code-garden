## CNN —— 卷积神经网络

### 底层本质

用**卷积核**在数据上滑窗扫描，提取局部特征。

> 你可以理解成：一个小过滤器，在图片上到处滑，找**边缘、纹理、形状**。

### 核心能力

-   抓空间结构
-   局部特征提取
-   权重共享 → 少参数、快
-   天生适合图像这种**网格数据**

### 典型场景

-   图片分类
-   目标检测
-   人脸识别
-   图像分割
-   语音频谱图（也能当图片用）

---

## ResNet（残差网络）

### 底层问题

普通 CNN 层数一多，反而更差（**梯度消失**）。

### ResNet 底层创新

加了一条 **shortcut（捷径 / 残差边）**，信号可以跳过某些层直接传过去。

### ResNet 核心能力

-   能堆超深层网络（几十～上百层）
-   深层也不会崩
-   特征更高级、更抽象

### ResNet 典型场景

-   所有高精度视觉任务
-   ImageNet 夺冠模型
-   现在大部分 CV 模型 backbone 都是 ResNet 变种

## DenseNet（密集连接网络）

### 核心定位

DenseNet 也是 CNN 的「加强版」。先给一个总定位，避免混乱：

-   **RNN** → 管「序列 / 时间」，和 CNN 是两条路
-   **CNN** → 视觉基础款，抓空间局部特征
-   **ResNet** → CNN 的「深层版」（靠捷径解决层数深了崩的问题）
-   **DenseNet** → CNN 的「全连接版」（靠密集连接榨干每一层的特征）

> **一句话总结**：ResNet 是"层跳着连"，DenseNet 是"层全连着"。

### 一、DenseNet 底层本质：「密集连接」的 CNN

先从最核心的结构讲，用直观的比喻：

#### 1. 普通 CNN：「单行道」

普通 CNN 的层是「一层输出给下一层」，就像：

```text
层1 → 层2 → 层3 → 层4
```

只有相邻层能传递信息，前面层的特征到后面就丢了。

#### 2. ResNet：「加了一条近路」

ResNet 给层加了「shortcut 捷径」，信号可以跳过中间层：

```text
层1 → 层2 → 层3 → 层4
      ↑        ↑
层1 ──┴────────┘ （捷径直接连到层3、层4）
```

核心是**「跨层求和」**：当前层输出 = 自己的计算结果 + 前面某层的原始信号，解决"层数深了特征丢光"的问题。

#### 3. DenseNet：「全搭天桥」

DenseNet 直接让每一层都和所有前面的层连起来，没有"跳过"，只有"全连接"：

```text
层1 → 层2 → 层3 → 层4
      ↑     ↑     ↑
层1 ──┴─────┴─────┘
            ↑     ↑
层2 ────────┴─────┘
                  ↑
层3 ──────────────┘
```

核心是**「跨层拼接」**：当前层输入 = 自己的输入 + 前面**所有**层的输出（不是求和，是把特征拼在一起）。

> **简单说**：
>
> -   ResNet："我把前面**某一层**的特征加进来"
> -   DenseNet："我把前面**所有层**的特征都拼进来"

### 二、DenseNet 对比 ResNet / CNN / RNN：核心能力差异

| 模型        | 核心能力                     | 底层特点           | 优点                      | 缺点                   |
| ----------- | ---------------------------- | ------------------ | ------------------------- | ---------------------- |
| CNN（基础） | 提取局部空间特征             | 层间单向传递       | 简单、快、参数少          | 层数深了特征丢失       |
| ResNet      | 深层提取特征，不崩           | 跨层"求和"捷径     | 深层稳定、精度高          | 只复用部分层特征       |
| DenseNet    | 极致复用所有层特征，精度更高 | 跨层"拼接"密集连接 | 特征复用率 100%、精度更高 | 参数多、计算慢、耗内存 |
| RNN         | 处理序列 / 时序数据，有记忆  | 按时间步循环传递   | 适配顺序数据              | 长序列忘事、速度慢     |

#### 关键补充（初学者必懂）

-   **DenseNet 为什么精度更高？**
    每一层都能拿到前面所有层的特征（比如层 4 能拿到层 1、2、3 的全部特征），相当于"每一步都能回看所有历史信息"，不会漏掉浅层的细节（比如图片的边缘、纹理），所以对复杂图像的识别更准。

-   **DenseNet 为什么没 ResNet 流行？**
    密集连接会导致特征图越拼越多，内存和计算量暴涨（比如 ResNet 跑 100 层很轻松，DenseNet 跑 100 层可能卡爆）。工业界更看重"精度 + 速度"平衡，所以 **ResNet 是主流**，DenseNet 只用于"追求极致精度、不介意速度"的场景（比如学术竞赛）。

### 三、DenseNet 的使用场景（和其他模型对比）

#### 1. DenseNet 适用场景

-   学术研究 / 竞赛（追求 Top1 精度，不限制计算资源）
-   小数据集场景（特征复用率高，能减少过拟合）
-   医疗影像分析（比如 X 光、病理切片识别，需要极致细节，不在乎计算速度）

#### 2. 不适用场景

-   工业落地（比如手机端、实时检测）：速度慢、耗内存，不如 ResNet 实用
-   实时性要求高的任务（比如视频实时目标检测）
-   序列 / 时序任务（比如文本、语音）：不如 RNN / Transformer，完全不适用

#### 3. 各模型场景总结（对比回顾）

-   **RNN** → 文本 / 语音 / 时间序列（比如股价预测、语音转文字）
-   **基础 CNN** → 简单图像任务（比如验证码识别、简单分类）
-   **ResNet** → 工业级视觉任务（人脸识别、自动驾驶目标检测、电商商品分类）
-   **DenseNet** → 高精度小众场景（学术竞赛、医疗影像、小数据集图像分析）

---

## 总结

-   **核心定位**：DenseNet 是 CNN 的"极致特征复用版"，和 ResNet 同属深层 CNN，但连接方式从"跨层求和"变成"全层拼接"。

-   **核心区别**：ResNet 解决"深层 CNN 崩了"的问题；DenseNet 解决"CNN 特征复用不充分"的问题——前者平衡速度和精度，后者极致精度但牺牲速度。
-   **使用选择**：工业界优先 **ResNet**，追求极致精度选 **DenseNet**，处理序列选 **RNN / Transformer**，简单图像任务用**基础 CNN**。
