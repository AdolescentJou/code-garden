# 第5天：训练优化器与学习率调度—— AdamW原理、warmup+cosine decay、梯度裁剪

**一句话总结**：训练大模型像驾驶巨轮——优化器控制方向，学习率调度控制速度，梯度裁剪防止翻船。三者配合才能稳定航行。

**前置知识**：基础梯度下降、随机梯度下降（SGD）、矩阵运算、第4天预训练方法论。

---

### 核心概念

#### 1.1 训练大模型的优化问题

训练大模型本质是一个优化问题：给定损失函数 $L(\theta)$，找一组参数 $\theta$ 使 $L$ 最小。

核心更新公式：$\theta_{t+1} = \theta_t - \eta \cdot \nabla L(\theta_t)$

其中 $\eta$ 是学习率， $\nabla L$ 是梯度。

**听起来简单，但实际训练百亿参数模型时，会遇到大量问题**：

1. 不同参数的梯度大小差异巨大——有些参数需要大步更新，有些需要小步
2. 训练初期参数随机，梯度方差大——大学习率会导致训练崩溃
3. 某些层的梯度可能突然爆炸——参数更新失控，loss变成NaN

为了解决这些问题，我们需要三个工具：**AdamW优化器**、**学习率调度**、**梯度裁剪**。

#### 1.2 AdamW 优化器

##### 为什么需要自适应学习率？

**问题**：在深度网络中，不同层的梯度大小可能差几个数量级。如果用统一学习率，大梯度的层已经"跳过了"最优解，小梯度的层还在原地踏步。

**类比**：一群人一起走路，有人腿长有人腿短。如果所有人都迈同样大的步子，腿长的人走太快（overshoot），腿短的人走太慢（收敛慢）。

**解决方案**：让每个参数有自己的"步长"——梯度大的参数用小学习率，梯度小的参数用大学习率。

##### Adam算法详解

Adam = Adaptive Moment Estimation（自适应矩估计）

它维护两个移动平均：

- **一阶矩（动量）**：梯度的指数移动平均，相当于"惯性"
- **二阶矩**：梯度平方的指数移动平均，相当于"梯度大小的估计"

```
// 代码块
# Adam更新规则
m = β1·m + (1-β1)·g          # 一阶矩（动量）：梯度的方向
v = β2·v + (1-β2)·g²         # 二阶矩：梯度的大小
m̂ = m / (1-β1^t)             # 偏差校正（初期估计偏低，需要校正）
v̂ = v / (1-β2^t)             # 偏差校正
θ = θ - η · m̂ / (√v̂ + ε)     # 参数更新
```

**逐步理解**：

1. **动量（m）**：像物理中的惯性——不只看当前梯度，还看历史梯度的加权平均。如果梯度方向一致，动量会加速；如果方向不一致，动量会减速。
  - 类比：滑雪时，如果你一直往一个方向滑，速度会越来越快（动量积累）；如果你来回拐弯，速度会被抵消。

1. **二阶矩（v）**：估计每个参数梯度的方差。梯度大的参数，v大，学习率被除以大数→自动减小。
  - 类比：路况复杂（梯度大）时减速，路况简单（梯度小）时加速。

1. **偏差校正**：因为m和v初始化为0，前几步的估计会偏低。除以 $(1-\beta^t)$ 进行校正，随着t增大，校正因子趋近1（校正量趋近0）。

1. **参数更新**：$\eta \cdot \hat{m} / (\sqrt{\hat{v}} + \epsilon)$
  - 分子：方向（动量）
  - 分母：步长缩放（二阶矩的平方根）
  - 效果：每个参数有自己的有效学习率

##### AdamW vs Adam 的关键区别

**Adam的问题**：权重衰减（L2正则化）被包含在梯度中，自适应学习率会改变衰减效果。

**AdamW的解决方案**：把权重衰减**独立**于梯度更新：

```
// 代码块
# Adam: 权重衰减混在梯度中
g = g + λ·θ                    # 梯度 + L2正则
m = β1·m + (1-β1)·g
v = β2·v + (1-β2)·g²
θ = θ - η · m̂ / (√v̂ + ε)

# AdamW: 权重衰减独立
m = β1·m + (1-β1)·g            # 只用原始梯度
v = β2·v + (1-β2)·g²
θ = θ - η · m̂ / (√v̂ + ε) - η·λ·θ  # 权重衰减单独加
```

**为什么这很重要？** 在Adam中，权重衰减被自适应学习率缩放了——大梯度的参数权重衰减更多，小梯度的参数权重衰减更少。这不合理！AdamW让权重衰减对所有参数一致。

**大模型常用配置**：β1=0.9, β2=0.95（注意不是0.999！）, ε=1e-8, weight_decay=0.1

**为什么β2=0.95而不是0.999？** 大模型训练中梯度变化更快，用更小的β2让二阶矩估计更敏感于最近的梯度变化。

#### 1.3 学习率 Warm-up + Cosine Decay

##### Warm-up（预热）

**问题**：训练初期，模型参数是随机初始化的，梯度方向不可靠。如果直接用大学习率，参数会被推到极端区域，训练就崩了。

**类比**：开车上高速——不是一启动就踩油门到底，而是先慢速起步，等方向稳了再加速。

**方法**：学习率从0线性增长到目标值：

```
// 代码块
lr = base_lr × (current_step / warmup_steps)
```

**为什么warmup有效？**

1. **训练初期梯度方差大**：随机参数产生随机梯度，大学习率会放大噪声
2. **Adam的二阶矩估计初期偏差大**：样本太少，估计不准。warmup给了Adam"热身"时间
3. **让模型先找到一个好的"方向"**：初期小步走，等方向稳定了再大步前进

##### Cosine Decay（余弦退火）

warmup结束后，学习率按余弦函数从最大值衰减到最小值：

$$\eta_t = \eta_{min} + \frac{1}{2}(\eta_{max} - \eta_{min})\left(1 + \cos\left(\frac{t}{T}\pi\right)\right)$$

其中t是当前步数，T是总步数。

**为什么用余弦而不是线性衰减？**

- 余弦衰减在开始和结束时变化慢，中间变化快
- 开始时保持较高学习率更久（充分学习）
- 结束时缓慢降低（精细调优）

**典型学习率曲线**：

```
// 代码块
学习率
  │
  │     ╱╲
  │    ╱  ╲___
  │   ╱       ╲___
  │  ╱            ╲___
  │ ╱                  ╲___
  │╱                        ╲___
  └──────────────────────────────→ 训练步数
   warmup    cosine decay
```

大模型通常warmup_steps占总步数的1-2%。

#### 1.4 梯度裁剪（Gradient Clipping）

**问题**：训练中某些层的梯度可能突然变得非常大（梯度爆炸），导致参数更新失控，loss变为NaN。

**解决方案**：当梯度范数超过阈值时，按比例缩小：

$$g_{clipped} = g \cdot \frac{\text{clip\_value}}{\max(||g||, \text{clip\_value})}$$

**类比**：限速器——不管你踩多猛的油门，速度都不会超过上限。

常用clip_value：1.0（大模型）

### 技术细节

#### 2.1 完整的训练代码

```Python
// 代码块
import torch
import math

class CosineWarmupScheduler:
    """Warmup + Cosine Decay 学习率调度器"""
    def __init__(self, optimizer, warmup_steps, total_steps, min_lr=0.0):
        self.optimizer = optimizer
        self.warmup_steps = warmup_steps
        self.total_steps = total_steps
        self.min_lr = min_lr
        self.base_lr = optimizer.param_groups[0]['lr']
        self.current_step = 0
    
    def step(self):
        self.current_step += 1
        
        if self.current_step <= self.warmup_steps:
            # Warmup阶段：线性增长
            lr = self.base_lr * self.current_step / self.warmup_steps
        else:
            # Cosine Decay阶段
            progress = (self.current_step - self.warmup_steps) / \
                       (self.total_steps - self.warmup_steps)
            progress = min(progress, 1.0)
            lr = self.min_lr + 0.5 * (self.base_lr - self.min_lr) * \
                 (1 + math.cos(math.pi * progress))
        
        for param_group in self.optimizer.param_groups:
            param_group['lr'] = lr
        
        return lr


def create_optimizer(model, lr=1.5e-4):
    """创建AdamW优化器"""
    # 分离需要权重衰减和不需要的参数
    decay_params = []
    no_decay_params = []
    
    for name, param in model.named_parameters():
        if param.requires_grad:
            if 'bias' in name or 'norm' in name or 'layernorm' in name:
                no_decay_params.append(param)
            else:
                decay_params.append(param)
    
    optimizer = torch.optim.AdamW(
        [
            {'params': decay_params, 'weight_decay': 0.1},
            {'params': no_decay_params, 'weight_decay': 0.0}
        ],
        lr=lr,
        betas=(0.9, 0.95),
        eps=1e-8
    )
    
    return optimizer


def train_step(model, batch, optimizer, scheduler, clip_value=1.0):
    """完整的训练步骤"""
    optimizer.zero_grad()
    
    # 前向传播
    loss = model(batch)
    
    # 反向传播
    loss.backward()
    
    # 梯度裁剪（防止梯度爆炸）
    grad_norm = torch.nn.utils.clip_grad_norm_(
        model.parameters(), max_norm=clip_value
    )
    
    # 参数更新
    optimizer.step()
    
    # 学习率调度
    current_lr = scheduler.step()
    
    return {
        'loss': loss.item(),
        'grad_norm': grad_norm.item(),
        'lr': current_lr
    }


# 使用示例
model = ...  # 你的模型
optimizer = create_optimizer(model, lr=1.5e-4)
scheduler = CosineWarmupScheduler(
    optimizer, 
    warmup_steps=2000, 
    total_steps=1400000
)

for step, batch in enumerate(train_loader):
    metrics = train_step(model, batch, optimizer, scheduler)
    
    if step % 100 == 0:
        print(f"Step {step}: loss={metrics['loss']:.4f}, "
              f"grad_norm={metrics['grad_norm']:.4f}, "
              f"lr={metrics['lr']:.2e}")
```

#### 2.2 不同优化器对比

| 优化器 | 核心思想 | 优点 | 缺点 | 适用场景 |
| --- | --- | --- | --- | --- |
| SGD | 固定学习率 | 简单 | 收敛慢 | 小模型 |
| Momentum | 加入动量 | 加速收敛 | 学习率固定 | CNN |
| Adam | 自适应学习率+动量 | 快速收敛 | 权重衰减有问题 | 通用 |
| AdamW | Adam+独立权重衰减 | 大模型标配 | - | **大模型** |

#### 为什么大模型训练容易崩？

大模型训练的"三座大山"：

1. **梯度爆炸**：百亿参数的网络中，梯度连乘效应极其严重
2. **loss spike**：训练中loss突然飙升然后恢复，可能导致模型质量下降
3. **数值不稳定**：混合精度训练中，FP16的数值范围有限

**应对措施**：

- 梯度裁剪（防止爆炸）
- Warmup（初期稳定）
- 小心选择β2=0.95（更敏感的梯度估计）
- 权重衰减0.1（防止过拟合）

### 常见误区

**误区1：学习率越大训练越快**

**事实**：学习率太大会导致训练不稳定甚至崩溃。大模型训练中，学习率通常很小（1e-4到3e-4）。

**误区2：AdamW和Adam差不多**

**事实**：在大模型训练中，Adam的权重衰减被自适应学习率扭曲，效果明显不如AdamW。

**误区3：warmup只是为了稳定**

**事实**：warmup不仅稳定训练，还能提升最终模型质量。实验表明，没有warmup的模型最终loss更高。
