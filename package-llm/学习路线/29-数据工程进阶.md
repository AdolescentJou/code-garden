**"垃圾进，垃圾出"（Garbage In, Garbage Out）**：

- 模型能力上限由数据质量决定
- 训练技巧只能提升10%，数据质量能提升50%
- 用低质量数据训练，再好的模型架构也白搭

#### 数据飞轮（Data Flywheel）

> 类比：陀螺仪。一旦转起来，就会越转越快、越转越稳。

```
// 代码块
数据飞轮的运作方式：

  第1轮：
  ├─ 用100万条人工数据训练 → 7B模型（初版）
  │
  第2轮：
  ├─ 用初版模型生成50万条合成数据
  ├─ 人工审核+清洗 → 高质量数据
  ├─ 100万 + 50万 = 150万条数据
  ├─ 训练 → 7B模型（更强）
  │
  第3轮：
  ├─ 用更强的模型生成75万条合成数据
  ├─ 人工审核+清洗 → 高质量数据
  ├─ 150万 + 75万 = 225万条数据
  ├─ 训练 → 7B模型（更强）
  │
  ...循环往复，模型越来越强

  关键：每轮生成的数据质量必须不低于原始数据
       否则会"劣化"（模型崩溃）
```

**数据飞轮的关键条件**：

1. **数据质量验证**：每轮合成的数据必须经过质量检查
2. **多样性保证**：合成数据不能和原数据太相似（避免过拟合）
3. **人类反馈**：定期用人类标注校正方向
4. **避免模型崩溃**：纯合成数据训练会导致模型输出越来越单一

#### 去重策略详解

##### 精确去重（Exact Deduplication）

```
// 代码块
方法：MD5/SHA256哈希去重
原理：对每段文本计算哈希值，哈希相同=文本相同

  文本A → MD5("文本A") = "abc123..." → 已存在？跳过
  文本B → MD5("文本B") = "def456..." → 新的，保留
  
优点：简单高效，O(1)查找
缺点：只能找到完全相同的文本，改一个字就找不到了
效果：能去掉5-10%的完全重复
```

##### 模糊去重（Fuzzy Deduplication）

```
// 代码块
方法1：MinHash + LSH（最常用）

  原理：
  1. 把文本转为n-gram集合（如3-gram）
     "我爱北京" → {"我爱北", "爱北京"}
  
  2. 用MinHash计算文本的"指纹"（签名）
     MinHash: 对每个n-gram计算多个哈希函数，取最小值
     → 生成128维的签名向量
  
  3. 用LSH（Locality Sensitive Hashing）快速查找相似文本
     → 相似度>85%的文本被认为是重复
  
  效果：能去掉10-20%的近似重复（改写、翻译、不同来源的相同内容）

方法2：嵌入相似度
  ├─ 用Sentence-BERT计算每段文本的嵌入
  ├─ 计算两两之间的余弦相似度
  └─ 过滤相似度>0.95的
  
  优点：能找到语义重复
  缺点：计算量大（O(N²)），需要近似最近邻搜索加速
```

#### 数据质量评估

| 指标 | 定义 | 评估方法 | 目标值 |
| --- | --- | --- | --- |
| **去重率** | 重复数据占比 | MD5/MinHash | 去重后<5% |
| **困惑度（PPL）** | 语言模型预测文本的难度 | 用GPT-2计算 | <100 |
| **n-gram重复率** | 文本内部重复程度 | 4-gram分析 | <1.0% |
| **有害内容率** | 包含有害内容的比例 | 分类器/规则 | <0.1% |
| **语言分布** | 各语言占比 | 语言检测 | 符合预期 |
| **领域覆盖** | 各主题分布 | 主题分类 | 均匀/按需求 |
| **平均长度** | 文本平均token数 | tokenizer | 100-10000 |

### 技术细节

#### 完整数据清洗Pipeline（Python实现）

```Python
// 代码块
import hashlib
import re
from collections import Counter
from typing import List, Optional

class DataCleaner:
    """大模型训练数据清洗Pipeline"""
    
    def __init__(self, target_lang='zh', min_length=20, max_length=100000):
        self.target_lang = target_lang
        self.min_length = min_length
        self.max_length = max_length
        self.seen_hashes = set()  # 精确去重
        self.stats = {
            'total': 0,
            'after_normalize': 0,
            'after_dedup': 0,
            'after_quality': 0,
            'after_lang': 0,
        }
    
    def clean_pipeline(self, text: str) -> Optional[str]:
        """完整清洗流程"""
        self.stats['total'] += 1
        
        # 1. 格式统一化
        text = self._normalize(text)
        if not text:
            return None
        self.stats['after_normalize'] += 1
        
        # 2. 精确去重
        if self._exact_dedup(text):
            return None
        self.stats['after_dedup'] += 1
        
        # 3. 质量检查
        if not self._quality_check(text):
            return None
        self.stats['after_quality'] += 1
        
        # 4. 语言过滤
        text = self._language_filter(text)
        if not text:
            return None
        self.stats['after_lang'] += 1
        
        return text
    
    def _normalize(self, text: str) -> str:
        """格式统一化"""
        # 去除HTML标签
        text = re.sub(r'<[^>]+>', '', text)
        # 去除URL
        text = re.sub(r'https?://\S+', '', text)
        # 去除邮箱
        text = re.sub(r'\S+@\S+', '', text)
        # 去除多余空白
        text = re.sub(r'\s+', ' ', text).strip()
        # 统一引号
        text = text.replace('"', '"').replace('"', '"')
        text = text.replace(''', "'").replace(''', "'")
        return text if text else None
    
    def _exact_dedup(self, text: str) -> bool:
        """精确去重（MD5哈希）"""
        text_hash = hashlib.md5(text.encode('utf-8')).hexdigest()
        if text_hash in self.seen_hashes:
            return True  # 重复
        self.seen_hashes.add(text_hash)
        return False
    
    def _quality_check(self, text: str) -> bool:
        """质量检查"""
        # 长度检查
        if len(text) < self.min_length or len(text) > self.max_length:
            return False
        
        # 重复率检查（4-gram）
        tokens = list(text)  # 中文按字切分
        if len(tokens) < 4:
            return False
        
        ngrams = [tuple(tokens[i:i+4]) for i in range(len(tokens)-3)]
        if not ngrams:
            return False
        
        unique_ratio = len(set(ngrams)) / len(ngrams)
        if unique_ratio < 0.7:  # 重复率>30%→低质量
            return False
        
        # 检查是否包含太多特殊字符
        special_chars = sum(1 for c in text if not c.isalnum() and not c.isspace() and c not in '，。！？、；：""''（）')
        if special_chars / len(text) > 0.3:
            return False
        
        return True
    
    def _language_filter(self, text: str) -> Optional[str]:
        """语言过滤"""
        try:
            from langdetect import detect
            lang = detect(text)
            if lang != self.target_lang and self.target_lang != 'all':
                return None
        except:
            pass  # 检测失败则保留
        return text
    
    def get_stats(self):
        """获取清洗统计"""
        return self.stats

# 使用示例
cleaner = DataCleaner(target_lang='zh')

raw_data = [
    "大模型是指参数规模巨大的神经网络模型，通常包含数十亿到数千亿个参数。",
    "大模型是指参数规模巨大的神经网络模型，通常包含数十亿到数千亿个参数。",  # 重复
    "asdfghjkl",  # 太短/无意义
    "<html><body>这是网页内容</body></html>",  # HTML
    "正常的高质量文本内容...",
]

cleaned_data = []
for text in raw_data:
    result = cleaner.clean_pipeline(text)
    if result:
        cleaned_data.append(result)

print(f"清洗前: {len(raw_data)} 条")
print(f"清洗后: {len(cleaned_data)} 条")
print(f"统计: {cleaner.get_stats()}")
```

#### MinHash + LSH 模糊去重

```Python
// 代码块
from datasketch import MinHash, MinHashLSH

def fuzzy_dedup(texts: List[str], threshold: float = 0.85, num_perm: int = 128) -> List[str]:
    """
    使用MinHash + LSH做模糊去重
    
    参数：
    - texts: 文本列表
    - threshold: 相似度阈值（>这个值认为是重复）
    - num_perm: MinHash排列数（越大越精确但越慢）
    """
    # 创建LSH索引
    lsh = MinHashLSH(threshold=threshold, num_perm=num_perm)
    
    clean_texts = []
    for idx, text in enumerate(texts):
        # 创建MinHash签名
        mh = MinHash(num_perm=num_perm)
        
        # 用3-gram作为特征
        tokens = list(text)
        for i in range(len(tokens) - 2):
            ngram = ''.join(tokens[i:i+3])
            mh.update(ngram.encode('utf-8'))
        
        # 查询是否有相似文本
        similar = lsh.query(mh)
        
        if not similar:
            # 没有相似的，保留
            lsh.insert(str(idx), mh)
            clean_texts.append(text)
    
    return clean_texts

# 使用示例
texts = [
    "大模型是参数规模巨大的神经网络模型",
    "大模型是指参数规模巨大的神经网络模型",  # 高度相似
    "今天天气真好",
    "今天天气真不错",  # 高度相似
    "Python是一种编程语言",
]

result = fuzzy_dedup(texts, threshold=0.7)
print(f"去重前: {len(texts)} 条")
print(f"去重后: {len(result)} 条")
# 去重前: 5 条
# 去重后: 3 条（去掉了2条相似的）
```

### 常见误区

**❌ 误区1：合成数据=假数据**
合成数据不是"假数据"。它是受控生成的、经过验证的、有质量保证的数据。和模型"幻觉"完全不同——幻觉是无意识的错误，合成数据是有目的的、经过筛选的。

**❌ 误区2：数据越多越好**
低质量数据多了反而有害。Llama-3用15万亿Token，但清洗后只保留了50%。关键是质量不是数量。

**❌ 误区3：数据飞轮会自动变好**
数据飞轮需要持续的人工干预——审核合成数据质量、调整生成策略、防止模型崩溃。不维护的数据飞轮会"越转越慢"。

**❌ 误区4：去重只是去掉完全相同的文本**
精确去重只去掉5-10%的重复。模糊去重（改写、翻译、不同来源的相同内容）能再去掉10-20%。两者都需要做。

### 为什么重要

数据工程是**大模型训练的"基础设施"**：

- **"垃圾进，垃圾出"**：模型能力上线由数据质量决定
- **数据飞轮**：高质量数据→好模型→更好数据→更好模型
- **稀缺性**：公开高质量数据有限，合成数据能力是核心竞争力
- **合规**：数据清洗中的有害内容过滤和隐私保护是法律要求

**关键认知**：大模型训练中，**数据工程的时间占比可能超过50%**。训练代码可能2天写完，数据准备可能需要2个月。

### 小练习

**练习1**：解释为什么纯合成数据训练会导致"模型崩溃"（Model Collapse）。

**答案提示**：纯合成数据训练时，模型会逐渐丢失原始数据中的长尾分布（罕见但重要的信息）。每轮生成都会让分布更"平均"，最终模型输出越来越单一。这就像复印件的复印件——每复印一次质量就下降一些。解决方法：混合人工数据和合成数据。

**练习2**：设计一个数据清洗方案，处理100GB的网页抓取数据。包括：

1. 清洗步骤
2. 预期每步去除的数据比例
3. 最终保留的数据量

**答案提示**：

1. 步骤：格式统一化(去除HTML等) → 精确去重(5-10%) → 模糊去重(10-20%) → 质量过滤(30-40%) → 有害内容过滤(1-5%) → 语言过滤(按需)
2. 100GB → 90GB(格式化) → 81GB(精确去重) → 65GB(模糊去重) → 40GB(质量过滤) → 39GB(有害过滤) → 最终约35-40GB
