# 第1天：什么是大模型？—— 从统计语言模型到Transformer的百年进化

**一句话总结**：大模型本质上是一个"超大的统计语言模型"，通过对海量文本学习语言的统计规律，获得了理解和生成自然语言的能力。

**前置知识**：基础的概率论（条件概率、链式法则）。如果你完全没接触过概率，别怕——我们会在文章里一步步解释。

---

### 核心概念

#### 1.1 大模型到底是什么？

我们先从一个问题开始：**一台电脑是怎么学会说话的？**

想象你面前有一台全新的电脑，它一个字都不认识。你给它一个任务："看到前面的文字，猜后面的文字。" 就这么简单。

比如，你给它看："今天天气真好，我打算"

它可能会猜："去跑步"、"吃火锅"、"睡觉"……

哪个答案更可能？它不知道"跑步"和"火锅"哪个更好，但它知道哪个**概率更大**。

这就是大模型的核心任务：**预测下一个词的概率**。用数学语言说：

$$P(w_t | w_1, w_2, ..., w_{t-1})$$

意思是：在看到前面所有词之后，下一个词是 $w_t$ 的概率是多少？

**为什么是"概率"而不是"确定答案"？**

因为语言本身就具有不确定性。"今天天气真好，我打算"后面可以跟"去跑步"，也可以跟"去吃火锅"，也可以跟"在家睡觉"。模型的任务不是"回答正确"，而是**找出概率最大的那个词**。

**训练过程**：模型读了几十亿、几百亿个词，不断调整自己的内部参数，使得在已知前文的情况下，下一个词的概率分布越来越接近真实的分布。

**推理过程**：当你输入"今天天气真好，我打算"，模型会输出一个概率分布——"去"的概率是30%，"在家"的概率是15%，"去"后面跟"跑步"的概率是40%……然后从中采样生成文本。

#### 1.2 从N-gram到Transformer的演进之路

这个"预测下一个词"的任务，人类已经研究了30多年。每一代方法都在试图解决上一代的缺陷。让我们一步步来看。

##### 第一代：N-gram模型（统计时代，1990年代）

**类比**：想象你是一个只会背词典的AI。你背了一个巨大的统计表——比如"我"后面最常跟什么词？"我"后面跟"是"出现了1000次，跟"爱"出现了800次，跟"去"出现了500次……所以当你看到"我"时，你会说"是"的概率最高。

这就是**N-gram模型**的核心思想。N代表"前N-1个词"。最常见的是一元（N=1，只看当前词）、二元（N=2，看前一个词）、三元（N=3，看前两个词）。

**为什么叫"N-gram"？** gram是"词组"的意思。N-gram就是"N个词组成的词组"。二元模型看的是所有两个词的组合（bigram），三元模型看的是所有三个词的组合（trigram）。

**数学公式**：

以三元模型为例：

$$P(w_t | w_{t-2}, w_{t-1}) = \frac{\text{count}(w_{t-2}, w_{t-1}, w_t)}{\text{count}(w_{t-2}, w_{t-1})}$$

简单说：**某个三元组出现的次数，除以它前面两个词出现的次数**。这就是条件概率的直观定义。

**举个例子**：假设语料中"今天天气好"出现了10次，"今天天气"组合出现了15次，那么：

$$P(\text{好} | \text{今天}, \text{天气}) = \frac{10}{15} = 0.67$$

**致命缺陷**：

1. **维度灾难（Curse of Dimensionality）**：假设词汇表有5万个词，三元组合就有 $50000^3 = 125$ 万亿种可能！绝大部分组合在训练数据中**一次都没出现过**。
2. **长距离依赖丢失**：三元模型只看前两个词，完全看不到更早的上下文。比如"尽管天气不好，今天天气"——这里的"天气"应该和句子开头的"天气不好"关联，但三元模型只看"今天"和"天气"。
3. **数据稀疏**：真正有用的组合太少，统计不可靠。

**类比**：N-gram就像一个**死记硬背**的学生，背了所有见过的搭配，但遇到没见过的就手足无措。

##### 第二代：Word2Vec + RNN/LSTM（神经网络时代，2010年代）

这一代的思路发生了根本转变：**不背统计表格，而是让神经网络学会"理解"词的含义**。

###### Word2Vec：让词有"位置"

Word2Vec的核心思想是：**相似的词在向量空间中应该接近**。

怎么做到的呢？通过一个简单的神经网络——给定一个词，预测它周围的词（Skip-gram）或者给定周围的词，预测中心词（CBOW）。

**神奇的地方**：训练完成后，向量空间中出现了**线性关系**！

```
// 代码块
向量("国王") - 向量("男人") + 向量("女人") ≈ 向量("女王")
向量("北京") - 向量("中国") + 向量("日本") ≈ 向量("东京")
向量("巴黎") - 向量("法国") + 向量("意大利") ≈ 向量("罗马")
```

一个300维的向量竟然能捕捉到性别、国别、首都关系！这太神奇了。

**但是**，Word2Vec是**静态**的——每个词只有一个向量。"苹果"这个词在"吃苹果"和"苹果公司"中是同一个向量，模型无法区分。

###### RNN/LSTM：让网络有"记忆"

RNN（循环神经网络）像一个**逐字阅读**的人。每次都把当前词和之前的"记忆"混合在一起处理。

```
// 代码块
输入: "今天 天气 真 好"
  t=1: 看到"今天" → 隐藏状态 h1 → 输出
  t=2: 看到"天气" + 隐藏状态h1 → 隐藏状态 h2 → 输出
  t=3: 看到"真"   + 隐藏状态h2 → 隐藏状态 h3 → 输出
  t=4: 看到"好"   + 隐藏状态h3 → 隐藏状态 h4 → 输出
```

每一步的隐藏状态都包含了前面所有词的信息（理论上）。

**LSTM（长短期记忆）**是RNN的升级版。它通过三个"门"来控制信息的流动：

- **遗忘门（Forget Gate）**：决定丢弃哪些旧信息
- **输入门（Input Gate）**：决定保留哪些新信息
- **输出门（Output Gate）**：决定输出什么

类比：就像人的记忆系统——有些事会忘记（遗忘门），新信息会被记住（输入门），但回忆时只提取需要的部分（输出门）。

**但是**，RNN有一个根本性的限制：**必须串行计算**。前一个词处理完了，才能处理下一个词。这在大规模GPU并行计算时代是致命的——GPU的优势就是并行，RNN完全用不上。

类比：RNN就像一个**逐字阅读**的人，读完前面的才能看后面的，没法跳着看。

##### 第三代：Transformer（注意力时代，2017年至今）

Transformer的核心创新：**不再逐字处理，而是同时看所有词之间的关系**。

这就像一个人翻字典查词——不用一个字一个字读，而是直接跳到目标词，还能同时查看所有相关词条。

Transformer通过**Self-Attention**机制，让每个词都能直接"看到"序列中的其他所有词。

**关键洞察**：Self-Attention的计算可以**完全并行化**——所有词之间的相关性可以同时计算。这是Transformer能利用GPU大规模训练的核心原因。

##### 第四代：大模型时代（2020年至今）

当Transformer的架构搭好后，研究者们发现了一个惊人的规律：**模型越大，能力越强**。

关键发现——**涌现能力（Emergent Abilities）**：当参数量超过阈值（如GPT-3的1750亿），模型突然展现出训练目标中未显式优化的能力——few-shot learning、推理链（Chain-of-Thought）、代码生成等。

**涌现能力的例子**：

- 看到一个新任务（如翻译），只给几个例子，模型就能学会（few-shot learning）
- 能一步步推理复杂数学题（Chain-of-Thought）
- 能写Python、JavaScript代码
- 能进行多步逻辑推理

**但是**，这些能力**不是**被显式训练的——模型只是被训练来"续写文本"。

| 时代 | 代表方法 | 核心思想 | 局限 | 类比 |
| --- | --- | --- | --- | --- |
| 统计时代 (1990s) | N-gram | 用历史N-1个词预测下一个词 | 维度灾难，长距离依赖丢失 | 死记硬背背单词书 |

| 大模型时代 (2020-) | GPT-3、LLaMA、GPT-4 | 参数突破百亿级，涌现推理/代码等能力 | 训练成本极高 | 读了整个互联网 |

#### 1.5 Scaling Laws（规模法则）

大模型时代有一个核心发现：**模型性能随规模（参数、数据、算力）的增加呈幂律提升**。

核心公式：

$$L(N) = E + A \cdot N^{-\alpha}$$

其中：

- $L$ 是模型在测试集上的损失（越低越好）
- $N$ 是模型参数量
- $E$ 是理论最优损失（数据本身的随机性，无法更低）
- $A$ 和 $\alpha$ 是拟合参数（通过实验数据拟合得到）

**为什么这条公式如此重要？**

因为把损失画在**对数坐标**上，它和参数量呈一条**直线**！这意味着：

1. **可以预测**：先训练几个小模型，拟合出这条直线，就能**外推**预测大模型的表现
2. **不需要花几亿美元**训练一个模型才知道它行不行
3. **让AI从"炼金术"变成了"可预测"的科学**

**Chinchilla定律**（DeepMind 2022）：在给定算力预算下，模型参数和训练数据量应该**等比例增加**。通常的经验法则是：Token数 ≈ 参数量 × 20。

这推翻了GPT-3时代的经验——GPT-3用了1750亿参数但只训练了3000亿tokens，数据量不够。按Chinchilla定律，1750亿参数应该配3.5万亿tokens！

**Scaling Laws的局限**：

1. 这些规律是在**相对小的模型**上拟合出来的，外推到万亿参数级别时可能不准确
2. 公式假设数据可以无限供应，但**高质量文本是有限的**
3. 2024年有人发现DeepMind的Chinchilla最优配比公式有bug（损失函数取了均值而不是求和）
