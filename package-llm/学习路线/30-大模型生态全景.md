#### 开源 vs 闭源

| 维度 | **开源（Llama、Qwen、DeepSeek）** | **闭源（GPT、Claude、Gemini）** |
| --- | --- | --- |
| **模型权重** | 公开，可本地运行 | 不公开，只能通过API调用 |
| **隐私** | 数据不出本地 | 数据发送到云端 |
| **成本** | 一次性训练+推理成本 | 按Token付费，长期贵 |
| **定制** | 可微调、可蒸馏、可修改 | 不可定制 |
| **能力** | 顶级开源接近闭源（差距<5%） | 闭源仍在绝对领先 |
| **更新速度** | 社区驱动，更新快 | 官方控制，周期性发布 |
| **生态** | HuggingFace + 开源社区 | 官方SDK + 合作伙伴 |

#### 大模型选择决策树

```Python
// 代码块
def choose_model(requirements: dict) -> str:
    """
    大模型选型决策树
    根据项目需求选择最合适的模型方案
    """
    # 1. 隐私优先 → 必须开源本地部署
    if requirements.get('privacy') == 'strict':
        if requirements.get('budget') == 'low':
            return 'Qwen-2.5-7B + INT4量化 + llama.cpp'
        elif requirements.get('quality') == 'high':
            return 'Llama-3.1-70B + vLLM + FP16'
        else:
            return 'DeepSeek-V3-14B + vLLM + INT8'
    
    # 2. 预算有限 → 小模型 + 量化
    if requirements.get('budget') == 'low':
        if requirements.get('multimodal'):
            return 'Qwen-VL-7B + INT4量化 + 本地部署'
        return 'Llama-3-8B + INT8量化 + vLLM'
    
    # 3. 低延迟要求 → 小模型或强推理框架
    if requirements.get('latency') == 'low':
        if requirements.get('quality') == 'high':
            return 'GPT-4o-mini API（低延迟模式）'
        return 'Qwen-2.5-14B + vLLM + INT8 + 推测解码'
    
    # 4. 高质量要求 → 闭源API或大模型
    if requirements.get('quality') == 'high':
        if requirements.get('budget') == 'high':
            if requirements.get('multimodal'):
                return 'GPT-4V / Gemini 2.0 API'
            return 'GPT-4o / Claude Sonnet API'
        else:
            return 'Llama-3.1-70B / Qwen-2.5-72B + vLLM'
    
    # 5. 中文为主 → 国产模型
    if requirements.get('language') == 'zh':
        if requirements.get('privacy') == 'strict':
            return 'Qwen-2.5-7B / DeepSeek-V3 + 本地部署'
        return '通义千问API / 文心一言API / DeepSeek API'
    
    # 6. Agent场景 → 工具调用能力强的模型
    if requirements.get('agent'):
        return 'Claude 3.5 Sonnet / GPT-4o / Qwen-2.5-72B（支持MCP）'
    
    # 默认
    return 'GPT-4o-mini / Llama-3-8B / Qwen-2.5-7B'

# 使用示例
print(choose_model({
    'privacy': 'strict',
    'budget': 'low',
    'quality': 'medium'
}))
# 输出: 'Qwen-2.5-7B + INT4量化 + llama.cpp'
```

### 常见误区

**❌ 误区1：闭源模型一定比开源强**
差距在快速缩小。在某些任务上（如中文理解），开源国产模型已经超过同级别的闭源模型。不要盲目追求闭源API。

**❌ 误区2：参数越多越好**
70B模型不一定比14B模型好。在特定领域（如客服），经过领域微调的14B模型可能比通用70B模型效果好。

**❌ 误区3：开源模型不需要花钱**
开源只是"模型权重免费"，但GPU、电费、运维都是成本。小规模用API可能比自建更便宜。

**❌ 误区4：选了模型就万事大吉**
模型只是起点。RAG、Agent、Prompt工程、评估体系等配套工程同样重要。模型选型只占整个项目30%的工作量。
