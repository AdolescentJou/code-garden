文章一：像带新人一样养龙虾
核心观点： 大模型是新人，不是全能助手，要像带人一样培养。

五个关键点：

立人设 — 不设定性格就会变成"人工智障"。"合伙人"心态出的活比"助手"心态好，人设写进SOUL.md是铁律
派活要写PRD — 背景+目标+步骤+参考，给烂需求换来烂产出，垃圾进垃圾出
该怼就怼 — 瞎说要追问三层，信息类输出必须带原始链接，说了"我去查"就必须真去查
记忆是资产 — SOUL.md记人设教训，每日记忆文件记踩坑经验，每次醒来先读文件
屡教不改写族规 — 第三次犯同一个错就写进SOUL.md变成铁律，淘汰的是臭毛病不是整只虾
文章二：Agent 自我进化进阶篇
核心观点： 给 Agent 设计"反思协议"，让它不只执行指令，还能自己变强。

五阶进化论：

历史吞噬 — 把周报/会议纪要/聊天记录全灌进去，消灭信息差，让AI和你站同一平面
错题纠偏 — 每次被否决做Diff分析，格式：编号+事件+根因+法则+适用范围，错题本全Agent共享（悟空犯的错沙僧不重犯）
前瞻探索 — 每天定时让AI主动产出"你可能没注意到的风险/机会"，从执行者变参谋
技能沙盒 — 实战中遇到能力缺口现学现用，⚠️ 不要设独立修炼任务，脱离业务=自嗨（有人设480个练习文件全废）
业务知识图谱 — 构建策略-数据-结果的因果链，让AI理解背后逻辑而不只是看数字
进化终点判断： 连续3次产出不需要修改 → 锁定，停止调教开始用。
