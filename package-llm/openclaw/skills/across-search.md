# 概览

cross-search 是一个并行搜索 8 大数据源、交叉验证信息可靠性、输出带置信度评分的结构化搜索 skill。支持快速搜索和深度研究两种模式，可被其他 skill 调用作为信息采集基础设施。

---

## 搜索模式

| 模式 | 触发信号 | 数据源数量 | 输出 |
| --- | --- | --- | --- |
| 快速搜索 | "帮我查"、简单事实性问题、被其他 skill 调用 | 2-3 个最相关源 | 摘要 + 关键发现 |
| 深度研究 | "深度搜索"、"调研"、"分析"、复杂/争议性话题 | 全部相关源（5-8 个） | 完整报告 + 验证矩阵 |

**判断规则**：

- 用户明确指定 → 遵从用户
- 简单事实查询（"XX 是什么"、"XX 价格"）→ 快速搜索
- 涉及观点/趋势/争议/多方信息 → 深度研究
- 被其他 skill 调用且未指定 → 快速搜索

## 搜索执行流程

### Step 1: 查询分析

分析用户输入，确定：

- **核心主题**：提取关键实体和概念
- **搜索模式**：快速搜索 or 深度研究
- **话题类型**：科技 / AI / 财经 / 消费 / 新闻 / 生活 / 开源Linux / 币圈区块链 / 开源项目源码分析
- **是否需要源码阅读**：涉及开源项目实现原理时标记
- **时效要求**：实时（24h）/ 近期（7d）/ 不限
- **语言策略**：中文优先 / 英文优先 / 双语并行

### Step 2: 并行搜索

使用 Task 工具并行发起所有搜索：

- **快速搜索**：同时 2-3 个数据源
- **深度研究**：同时 5-8 个数据源

**查询构造规则**：

- **Web**：中英文双语查询
- **Twitter/X**：英文关键词 + hashtag
- **小红书**：中文口语化关键词
- **Reddit**：英文 + 指定 subreddit
- **知乎**：中文专业术语
- **微博**：中文 + 热搜标签
- **V2EX/linux.do**：中文 + 领域关键词

### Step 2.5: 源码阅读（开源项目分析时）

**触发条件**：话题涉及开源项目的实现原理、技术方案、源码解析。

**执行方式**：

1. 定位项目仓库
2. 阅读关键文件：README → 入口文件 → 核心模块 → 依赖声明 → 类型定义
3. 形成独立理解（非转述二手信息）
4. 与公开信息交叉验证

**输出要求**：

- 报告含"源码分析"章节，引用具体文件路径和代码片段
- 区分"源码事实"和"推测"
- 二手信息与源码不符时以源码为准

### Step 3: 去重与聚合

1. 合并不同数据源的相同信息
2. 标注每条信息的来源列表
3. 按主题聚类

### Step 4: 交叉验证

**5 条核心规则**：

1. **无单源声明**：重要结论必须 >=2 个独立来源支持，单源标注"待验证"
2. **来源层级**：官方/权威媒体 > 行业专家/KOL > 社区讨论 > 匿名来源
3. **时效优先**：最新信息权重更高，过时信息标注时间差
4. **双语交叉**：中英文相互验证可提升置信度（+15%）
5. **社媒需佐证**：纯社交媒体来源需有非社媒来源佐证

### Step 5: 输出结果

按模式输出对应格式。

## 置信度评分体系

### 评分等级

| 等级 | 分数 | 含义 | 条件 |
| --- | --- | --- | --- |
| 已确认 | 90-100% | 多源一致、权威来源支持 | >=3 源一致 + 含权威来源 |
| 高可信 | 70-89% | 多源支持、无矛盾 | >=2 源一致 |
| 中等可信 | 50-69% | 有支持但存在部分矛盾 | 2 源支持但有 1 源矛盾 |
| 低可信 | 30-49% | 仅少量来源或可靠性低 | 仅 1 权威源或仅社媒来源 |
| 未验证 | 0-29% | 单源或无法验证 | 单一来源且非权威 |

### 来源权重

| 来源类型 | 基础权重 | 示例 |
| --- | --- | --- |
| 官方声明/公告 | 1.0 | 公司官网、政府公告 |
| 权威媒体 | 0.9 | Reuters, 财新, BBC |
| 行业媒体 | 0.8 | TechCrunch, 36氪 |
| 专业社区高赞 | 0.6 | 知乎高赞、Reddit 高票、V2EX/linux.do 高赞帖 |
| KOL/认证账号 | 0.5 | X 蓝标、微博大V |
| 普通社区内容 | 0.3 | 一般帖子、评论 |
| 匿名/不明来源 | 0.1 | 无法溯源的信息 |

### 计算公式

```
基础置信度 = sum(支持来源权重) / sum(所有涉及来源权重) * 100

调整因子:
  + 15%  双语来源交叉验证（中英文来源均支持）
  + 10%  >=3 个独立来源支持
  + 5%   包含一手/官方来源
  - 20%  存在权威来源矛盾
  - 10%  仅社交媒体来源（无权威媒体佐证）
  - 15%  信息过时（>30 天，且为时效敏感话题）

最终置信度 = min(100, max(0, 基础置信度 + 调整因子之和))
```

### 计算示例

**声明**："NVIDIA H200 产能将在 Q2 翻倍"

| 来源 | 类型 | 权重 | 态度 |
| --- | --- | --- | --- |
| Reuters 报道 | 权威媒体 | 0.9 | 支持 |
| NVIDIA 官方博客 | 官方声明 | 1.0 | 支持 |
| X @分析师 | KOL | 0.5 | 支持 |
| Reddit r/hardware | 社区 | 0.3 | 部分支持 |
| 知乎回答 | 社区高赞 | 0.6 | 支持 |

```
支持来源权重 = 0.9 + 1.0 + 0.5 + 0.6 = 3.0
部分支持权重 = 0.3 * 0.5 = 0.15（部分支持按 50% 计入）
所有涉及来源权重 = 0.9 + 1.0 + 0.5 + 0.3 + 0.6 = 3.3

基础置信度 = (3.0 + 0.15) / 3.3 * 100 = 95.5%

调整因子:
  + 15%  中英文来源交叉验证
  + 10%  >=3 个独立来源
  + 5%   包含官方来源

最终置信度 = min(100, 95.5 + 30) = 100%  →  已确认
```

## 交叉验证算法

### 4 个阶段

#### 阶段 1: 声明提取

从所有搜索结果中提取关键声明（Key Claims）：

- 可独立验证的事实性陈述
- 排除纯观点/情绪表达
- 合并语义相同但措辞不同的声明
- 保留具体数字和细节

**声明类型**：事实、时间点、因果、趋势、引述

#### 阶段 2: 来源映射

为每条声明建立来源映射表，标注支持/矛盾/部分支持/未涉及。

#### 阶段 3: 置信度计算

按上述公式计算。

#### 阶段 4: 矛盾处理

| 矛盾类型 | 处理方式 |
| --- | --- |
| 数字矛盾 | 以官方/一手数据为准，标注差异 |
| 时间矛盾 | 以最新权威来源为准 |
| 因果矛盾 | 并列呈现，说明各自依据 |
| 立场矛盾 | 分析立场背景，中性呈现 |
| 新旧矛盾 | 优先新信息，标注信息演变 |

**矛盾升级规则**：

- 涉及核心结论 → 报告中显著标注
- 仅涉及细节 → 脚注或"矛盾与争议"章节
- 无法判断 → 明确声明"存在争议"

## 被其他 Skill 调用

cross-search 可作为信息采集基础设施被其他 skill 调用（如 stock-analysis）。

### 调用参数

| 参数 | 必选 | 说明 | 示例 |
| --- | --- | --- | --- |
| `query` | 是 | 搜索查询 | `"NVIDIA 最新财报分析"` |
| `mode` | 否 | `quick` / `deep`，默认 `quick` | `quick` |
| `sources` | 否 | 指定数据源子集 | `["web", "x", "reddit"]` |
| `freshness` | 否 | `realtime` / `recent` / `any`，默认 `any` | `recent` |
| `language` | 否 | `zh` / `en` / `both`，默认 `both` | `zh` |

### 调用示例

```yaml
使用 cross-search skill 搜索以下内容：
- query: "NVIDIA GB200 供应链最新动态"
- mode: deep
- sources: ["web", "x", "reddit", "知乎"]
- freshness: recent
- language: both
```

## 容错与降级

| 场景 | 降级策略 |
| --- | --- |
| `x-search-mcp` 不可用 | 改用 `web_search site:x.com` |
| `xiaohongshu-mcp` 不可用 | 改用 `web_search site:xiaohongshu.com` |
| 某数据源搜索超时 | 跳过该源，输出标注"[来源名] 未响应" |
| 所有专用工具不可用 | 仅用 `web_search` + site 限定，降低置信度 |
| 搜索结果为空 | 调整关键词重试一次 |
| 社区论坛源无结果 | 不重试，标注"该社区无相关内容" |
| 中英文结果差异大 | 在"矛盾与争议"中呈现 |
