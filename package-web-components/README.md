## 介绍

清楚的传递给用户功能所蕴含的意图

### 动效的价值
1）
- 增加体验舒适度： 让用户认知过程更为自然。
- 增加界面活力：第一时间吸引注意力，突出重点。
- 描述层级关系：体现元素之间的层级与空间关系。
- 提供反馈、明确意向：助力交互体验。

2）
- 平滑过渡，明确层级，使元素间衔接更自然，清晰表达界面及元素间的层级关系；
- 引导操作，增强反馈，营造视觉焦点，引导用户关注接下来的操作；
- 表明状态，缓解情绪，告知用户页面的当前状态，缓解用户负面情绪；
- 强化认知，个性体验，强化用户对品牌的认知，加深用户认可度，给用户愉悦的使用体验；

### 动效的意义
衡量一个动效是否有意义，我们可以通过以下几个标准来考核：

一个动效的存在是否合理：是否带有明确的目的性，助力交互体验，没有多余的动效。

动效与性能：不能出现大幅度波动丢帧或者卡顿现象, 动效的体验须是流畅的，并且不影响产品的性能。

### 动效的原则
自然、高效、克制

1）
- 自然，自然运动规律，保证视觉连贯，让用户感知到动作是自然的
- 高效，尽量节省过渡的时间，快速完成过渡的动画效果
- 克制，做有意义的动效，不去做太多的修饰而干扰用户

2）
- 真实自然，动效应该符合真实世界的物理规律，减少用户理解和认知成本。同时应保持视觉连续性，缓动过渡做到不卡、不闪、不跳；
- 快速响应，动效应该快速准确地对用户的操作做出响应。避免拖沓不干脆。
- 清晰聚焦，动效需重点突出，符合逻辑，保证信息的有效传达。同时需目的明确，或提升可用性，或加强品牌感知。
- 有效克制，控制时长和出现频率，避免动效幅度过大，干扰用户

### 速度

#### 时间

1）
响应时间

0(直接触发，无需提示，按钮、勾选、开关) - 0.1s(间接触发，一般无需提示，一般UI动画) - 1s(感知明显，但在承受范围内，需进行提示，加载动作、进度条、下载、上传等) - 10s(超出忍受值，继续等待可能离开，系统需做出其他响应，让用户离开、重新加载、或者显示剩余进度等)

持续时间

0 - 200ms(瞬间变化) - 300ms(小元素/轻微变化) - 500ms(大元素/复杂变化)

和设备有关

2）
基本持续时间单位
最快时间: 100ms, 基本时间: 200ms, 较大时间：300ms... 100 的倍增方式。

页面转换或其他时间单位
最快时间: 150ms, 基本时间: 300ms, 平滑时间：450ms, 较大时间: 600ms... 150 的倍增方式

缓入曲线(加速运动，离场，ease-in)、缓出曲线(减速运动，进场，ease-out)、缓动曲线(标准运动，范围内点到点，ease)、弹性曲线

### 空间

1）
现实空间里，物体存在远小近大的原则，运动则有远慢近快。
视差：例如汽车在公路上行驶，离汽车越近的物体，移动速度越接近汽车的速率。以行进中的汽车为例，汽车所在的点为 X 轴的基准点，离基准点越远时，速度就越慢。动效设计中同样存在这个原则，元素的空间距离会影响动画效果，从而影响动效设计的决策。
大小：遵循远处的物体小，近处的物体大的原则。

### 组合
1）
组合动效是将多种动画效果组合起来运用在单个元素或者界面中的表现方式，吸引用户的注意，让用户快速了解信息的主次关系。
单元素组合动画
多元素列队动画
多元素聚散动画

2）
编排就是对动效的过渡效果进行设计，让元素自然的过渡，让用户的注意力自然的被引导；
- 运动路径，元素不成比例的改变外观时，应该是弧线运动（相反成比例的话，直线运动
- 主次分明，主次分明的动效有助于在屏幕和体验之间创造更强的秩序感，还可以使用共享元素，例如标题面板或按钮来加强连续性
- 顺序合理，用户的注意应该沿着一个流向来引导，将列表内容的入口错开 20~25 毫秒可显着降低认知负荷（如果持续时间过长，可能会给人一种迟滞的观感）
表格式的布局，动效应该沿着视线流向运动（清晰的对角线方向，逐个显示，一方面耗时太长，另一方面会让用户觉得元素的加载方式是锯齿状的；

### 过渡
人脑灰质（Gray Matter）会对动态的事物（eg：移动、形变、色变等）保持敏感。 在界面中，适当的加入一些过渡效果，能让界面保持生动，同时也能增强用户和界面的沟通。

视觉连贯性三元素#
Adding:  新加入的信息元素应被告知如何使用，从页面转变的信息元素需被重新识别。

Receding:  与当前页无关的信息元素应采用适当方式移除。

Normal: 指那些从转场开始到结束都没有发生变化的信息元素。

## 动效的基本分类

1）
- 转场型，帮用户理解界面的层级逻辑关系。
- 反馈型，对用户的操作及时给出相应的反愦，告知用户产品的页面状态。给用户一定的心理预期
- 引导型，通过视觉和动效聚焦用户视线，吸引用户注意力，帮助产品业务达成某个模块的KPI。
- 展示型，为用户制造视觉上的愉悦，营造氛围，让用户 觉得有趣生动；

## 动效说明文档

清晰简明的动效说明文档可以让开发更好地还原效果，动效说明文档主要有以下原则：

- 包含”触发条件”，比如是通过点击、滑动等操作还是页面进出场触发
- 包含“对象”，截图表明哪部分元素对应的名称是什么，和下表中的对象名称进行对应
- 包含“动效描述”，有“变化属性、贝塞尔曲线、持续的时长”，通常我会在变化持续时长那条直线上表明对应属性的变化值
